# Identité visuelle d'ORSAT-LOG

Logo « carnet ouvert » : un carnet de trafic ouvert, le pic du signal dressé sur la reliure.
Même famille que le logo d'ORSAT SDR (PhantomSDR-ORSAT, `docs/branding/orsat-icon.svg`) :
fond bleu nuit `#0b1426` → `#1a2c4e`, vieil or `#cfb53b` (dégradé `#ecd77a` → `#9c8424`).

| Fichier | Usage |
|---|---|
| `orsat-log-icon.svg` | Logo vectoriel (source de toutes les autres images) |
| `orsat-log-icon-512.png` | Logo en PNG, 512 × 512 |

Icônes du navigateur dans `frontend/public/` (copiées dans `dist/` à chaque compilation) :
`orsat-log-icon.svg`, `orsat-log-icon-32.png`, `orsat-log-icon-192.png`, `orsat-log-icon-512.png`,
`apple-touch-icon.png`, `favicon.ico`. Elles sont publiques (servies sans connexion, page de connexion comprise).
